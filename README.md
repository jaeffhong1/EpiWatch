# Thesis Project for Disease Monitoring

This project utilises [low-rank adaptation (LoRA)] from (https://github.com/tloen/alpaca-lora) to fine-tune [Large Language Models (LLMs)] to automatically extract relations from disease related news articles. 

The task of the AI models are tuned to extract out semantic relationships between entities in raw unfiltered text. The relations are extracted as triplets, a data structure to pair entities and label their interrelation.
